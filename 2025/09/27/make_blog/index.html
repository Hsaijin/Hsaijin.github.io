2025/09/27

迁移最简单的方法

  1. 删除原blog根目录node_modules文件夹
  2. 执行环境准备
  3. 正常更新操作

仓库准备

  1. github repository 新建

    需保证用户名和新建的repository名一致，后续才能通过个人域名访问。
    如用户名：Hsaijin | 仓库名：Hsaijin.github.git.io

环境准备

  1. 安装 git

    git --v

  2. 安装 node.js from https://nodejs.org/zh-cn

    node -v and npm -v

  3. 配置 github ssh
  4. 安装HEXO npm install hexo-cli -g
  5. (如果是迁移则skip) 初始化 hexo init
  6. 安装组件 npm install
  7. 部署方法 npm install hexo-deployer-git --save，使得通过hexo d可以一键部署到remote，不用add/commit/push (但一样需要hexo g，)

更新操作

  1. hexo new "name" 新建文章 or hexo new page "name" 新建页面
  2. hexo g 生成页面, hexo d 部署仓库；or hexo g -d 生成页面并部署
  3. hexo s 本地预览 localhost:4000
  4. hexo clean 清除缓存和已生成的静态文件
